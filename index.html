// What is SurfManager?

WHAT IS THIS?

SurfManager is a powerful session and data management tool designed specifically for AI coding applications. It provides developers with complete control over their development environment data.

Built with efficiency and safety in mind, SurfManager automates the tedious process of backing up, restoring, and managing application sessions - allowing you to focus on what matters: coding.

SUPPORTED APPLICATIONS

✓ Cur**r

✓ Win**urf

✓ Visual Studio Code

✓ All VSCode-based editors and forks

+ Easily add custom applications via Manual Add Button in App configuration

USE CASES

→ Session Backup & Restore

Save your current workspace state and restore it later. Perfect for testing different configurations.

→ Multi-Environment Management

Switch between different development setups instantly. Maintain separate configurations for different projects.

→ Clean Reset

Reset your application to factory settings while keeping backups safe. Troubleshoot issues effectively.

→ Account Management

Manage multiple user accounts and sessions. Switch between different authentication states seamlessly.
